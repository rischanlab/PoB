# Experiment results

Run `npm run experiment` to generate:

- `scenario-results.csv`
- `gas-results.csv`

Run `npm run experiment:atomic-gas` to generate the atomic controller-token gas
evaluation:

- `atomic-gas-raw.csv`
- `atomic-gas-summary.csv`
- `atomic-gas-comparison.csv`

Do not commit hand-edited versions of these files. Regenerate them from the
code and record the Git commit used for the paper.
